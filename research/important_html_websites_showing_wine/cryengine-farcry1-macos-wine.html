Windows-to-macOS Application Porting Guide

Step 1 — Wineskin Winery Setup & .iso or setup.exe

We use Homebrew to install Wineskin and acquire Windows software from archives:

Open your Terminal and copy-paste this to install Homebrew if you don't have

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Now install Wineskin and acquire Windows software from archives:

# Clean environment setup
brew update
brew upgrade
brew uninstall --force --zap wineskin
brew install --cask --no-quarantine The-Wineskin-Project/wineskin/wineskin
brew install winetricks
You can extract .ico from .exe for step 5 https://tools-4all.com/extract-icon

Software Sources:

  • Archive.org - Legal abandonware and historical software
  • Original Installers - From original media when possible
  • Legal Considerations - Only preserve out-of-commerce software

After installation, launch Wineskin Winery and update to the latest wrapper version.

Step 2 — Wine Engine Management & Selection

You will also need to download this specific engine version to run 32bit FarCry1 on Big Sur. I tested on my MacBook Pro 2014 mid.

WS11WineCX20.0.4.tar.7z
https://github.com/vitor251093/porting-kit-engines/releases/download/wineskin/WS11WineCX20.0.4.tar.7z

You need to manually drop in the folder. Open Finder -> Go ->

~/Library/Application Support/Wineskin

You also might wanna try out other engines

https://cdn.gitgpt.chat/rtx/wineenginelist.html

Step 3 — Wine Wrapper Creation

Navigate to your Applications folder to locate and start Wineskin Winery

Wineskin Winery has two components:

  • -Wine Engine(WS11WineCX20.0.4.tar.7z)
  • -Wine Wrapper(Wineskin-3.0.6_2) 

If you don't see the engine, you need to click on 'Refresh' icon.

Once you confirmed the correct version numbers, click on 'Create New Blank Wrapper'

Step 4 — Load FarCry1.iso and start install.exe

Navigate to your Wineskin Applications folder to open content

~/Applications/Wineskin

Show package content

Click on 'Install Software'

Click on 'Choose Setup Executable'

Load your downloaded iso and select 'setup32.exe' as we are using 32bit version

Install into your Wineskin directory. Usually C:\Program Files\FarCry1

Make sure you install directx9 too during the setup

Step 5 — Create Exe for Editor and Game

Create separate exe app for Editor and FarCry1

Open Wineskin again -> Go to Advanced/Tools

In Tools click on 'Custom EXE Creator'

Navigate drive_c\Program Files\FarCry1\bin32

You can also find it in Finder -> Go

~/Applications/Wineskin/FarCry1.app/Contents/SharedSupport/prefix/drive_c/Program Files/FarCry1/bin32

Step 6 — Editor and game

Now you can start Editor.exe or FarCry.exe

If you want to run Editor and FarCry in the same time, you need to create a separate Wineskin

One for the Editor and one for FarCry
